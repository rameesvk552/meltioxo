WAYON POS AUTOMATIC INVOICE PRINTING
====================================

CLIENT COMPUTER REQUIREMENTS

1. Windows 10 or Windows 11.
2. HP Smart Tank 580 installed and able to print a Windows test page.
3. Microsoft Edge or Google Chrome.
4. Internet access to perfume.wayon.in.

INSTALLATION

1. Extract the complete setup folder on the client's computer.
2. Double-click "Install Wayon Auto Printing.cmd".
3. The installer detects the HP printer and creates a "Wayon POS" shortcut
   on the desktop.
4. Wayon opens in a dedicated window. Sign in once and allow the browser
   profile to remember the login.

DAILY USE

1. Switch on the HP Smart Tank 580 and confirm that it is connected.
2. Open "Wayon POS" from the desktop.
3. Complete a sale.
4. The invoice prints automatically without displaying the print dialog.

IMPORTANT

- Always open the POS using the installed "Wayon POS" desktop shortcut.
- Printing is sent to the printer detected during installation.
- If the printer is renamed or reinstalled, run the installer again.
- Keep this dedicated POS window on trusted pages only because browser print
  confirmation is disabled in this window.
